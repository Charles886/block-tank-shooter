# 🎮 Block Tank - 方塊射擊遊戲

一款刺激的塔防射擊遊戲，控制你的戰車射擊敵人方塊，躲避敵方火力！

## 📋 功能概述

- **實時射擊戰鬥** - 控制玩家戰車射擊敵人方塊
- **波次系統** - 隨著波次增加，敵人變得更強大更多
- **多種敵人類型** - 普通敵人和射擊型敵人，具有不同的行為模式
- **道具系統** - 收集掉落的強化道具提升戰鬥能力
- **動態視覺效果** - 粒子系統、光屏閃爍、螢幕震動
- **音效系統** - 完整的射擊、爆炸、傷害音效
- **響應式設計** - 支援桌面滑鼠和手機觸控操作
- **暫停功能** - 隨時暫停遊戲

## 🎮 遊戲操作

### 🖥️ 桌面版控制

#### 移動
- **W** - 向上移動
- **A** - 向左移動
- **S** - 向下移動
- **D** - 向右移動
- 可同時按多個方向鍵進行斜向移動
