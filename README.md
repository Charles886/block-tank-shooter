# 🎮 Block Tank - 方塊射擊遊戲
執行
https://charles886.github.io/block-tank-shooter/index.html


一款刺激的塔防射擊遊戲，控制你的戰車射擊敵人方塊，躲避敵方火力！

## 📋 功能概述

- **實時射擊戰鬥** - 控制玩家戰車射擊敵人方塊
- **波次系統** - 隨著波次增加，敵人變得更強大更多
- **多種敵人類型** - 普通敵人和射擊型敵人，具有不同的行為模式
- **道具系統** - 收集掉落的強化道具提升戰鬥能力
- **動態視覺效果** - 粒子系統、光屏閃爍、螢幕震動
- **音效系統** - 完整的射擊、爆炸、傷害音效
- **響應式設計** - 支援桌面滑鼠和手機觸控操作
- **暫停功能** - 隨時暫停遊戲

## 🎮 遊戲操作

### 🖥️ 桌面版控制

#### 移動
- **W** - 向上移動
- **A** - 向左移動
- **S** - 向下移動
- **D** - 向右移動
- 可同時按多個方向鍵進行斜向移動

#### 瞄準和射擊
- **滑鼠移動** - 移動滑鼠指向敵人方向（瞄準）
- **滑鼠左鍵按住** - 持續向滑鼠指向方向射擊
- **滑鼠左鍵釋放** - 停止射擊

#### 遊戲控制
- **空白鍵** - 暫停遊戲/繼續遊戲
- 暫停狀態下會顯示「暫停中」提示

### 📱 手機版控制

#### 移動和射擊
- **觸控並拖曳** - 手指按住並拖動即可移動，同時朝向手指位置方向射擊
- **手指離開螢幕** - 停止射擊

#### 遊戲控制
- **空白鍵**（如有藍牙鍵盤）- 暫停遊戲

#### 觸控操作詳細說明
1. 在遊戲區域內用手指按住
2. 拖動手指移動玩家方塊
3. 自動朝向手指方向射擊
4. 手指離開螢幕時停止射擊
5. 最多支援單點觸控操作

### 操作對比表

| 操作 | 桌面版 | 手機版 |
|------|--------|--------|
| 移動 | W/A/S/D | 觸控拖曳 |
| 瞄準 | 滑鼠移動 | 手指位置 |
| 射擊 | 滑鼠左鍵按住 | 觸控按住 |
| 停止射擊 | 滑鼠左鍵釋放 | 手指離開 |
| 暫停/繼續 | 空白鍵 | 空白鍵（可選） |

## 🎁 道具系統

遊戲中擊敗敵人有 20% 機率掉落道具：

| 道具 | 顏色 | 效果 | 持續時間 |
|------|------|------|---------|
| 治療 | 🟢 綠色 (#06d6a0) | 恢復 30 點生命值 | 立即生效 |
| 快速射擊 | 🔵 藍色 (#118ab2) | 提升射速（射速提升 50%） | 有限時間 |
| 三倍子彈 | 🔴 紅色 (#ef476f) | 同時發射三發子彈 | 有限時間 |

**道具獲取方式：**
- 擊敗敵人時隨機掉落
- 接觸道具方塊自動獲得
- 道具掉落後有時間限制，若不及時撿取會消失

## 🎯 遊戲機制

### 波次系統
- 每波需要擊敗 5 + 波數×2 個敵人才能進入下一波
- 敵人數量和難度隨波次遞增
- 敵人生成速度會逐漸加快
- 進入新波次時會顯示「WAVE X」提示

### 傷害系統
- **敵人子彈傷害** - 12 HP
- **敵人身體碰撞傷害** - 20 HP
- 受傷後有 45 幀的無敵時間（期間玩家會閃爍）
- 生命值降至 0 遊戲結束
- 每次受傷會產生粒子效果和震動反饋

### 敵人類型

**普通敵人** 🔴
- 顏色：紅色
- 簡單的移動和追蹤
- 低生命值，一擊即死
- 分數：10 分

**坦克敵人** 🟠
- 顏色：橙色
- 高耐久度（多次射擊才能擊敗）
- 顯示血條
- 擊敗時螢幕震動更強
- 分數：30 分

**射擊者敵人** 🟣
- 顏色：紫色
- 會朝玩家射擊
- 中等生命值
- 定期發射子彈攻擊（距離 < 420 像素時）
- 分數：20 分

| 敵人類型 | 分數 |
|----------|------|
| 普通敵人 | 10 分 |
| 坦克敵人 | 30 分 |
| 射擊者敵人 | 20 分 |

**評分倍增：**

- **HTML5 Canvas** - 遊戲渲染

## 📁 專案結構

```
Block_Tank/
├── index.html      # 主 HTML 檔案，包含遊戲容器和 UI
├── core.js         # 遊戲核心邏輯（狀態、輸入、更新、渲染）
├── entities.js     # 敵人和子彈的定義和生成
├── powerups.js     # 道具系統實現
├── sound.js        # 音效管理和播放
└── style.css       # 遊戲樣式和動畫
```

### 核心檔案說明

**index.html**
- 遊戲畫布和 HUD 元素（分數、生命、波次、道具顯示）
- 開始、暫停和遊戲結束畫面
- 遊戲操作說明

**core.js**
- 遊戲狀態管理
- 玩家控制和移動（支援鍵盤和滑鼠）
- 敵人 AI 和行為
- 碰撞檢測
- 遊戲渲染和主遊戲迴圈（60 FPS）
- 粒子效果系統

**entities.js**
- 敵人物件定義
- 玩家子彈和敵人子彈
- 邊緣隨機生成位置

**powerups.js**
- 道具定義（治療、快速射擊、三倍子彈）
- 道具生成和應用邏輯

**sound.js**
- 遊戲音效管理
- Web Audio API 初始化
- 音效類型：射擊、擊中、爆炸、受傷、波次、遊戲結束

**style.css**
- Canvas 容器和 HUD 樣式
- 按鈕和覆蓋層動畫
- 響應式設計（適配各種螢幕尺寸）

## 🌐 部署

該遊戲可直接在瀏覽器中運行。由於使用 Web Audio API，需在 HTTPS 連線或本地環境下運行。

**推薦部署選項：**
- GitHub Pages
- Vercel
- Netlify
- 任何靜態 Web 主機

**本地運行：**
```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Node.js (http-server)
npx http-server

# 然後在瀏覽器打開 http://localhost:8000
```
